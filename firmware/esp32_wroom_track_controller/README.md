# ESP32-WROOM-32 30 pin — управление двумя гусеницами

Прошивка PlatformIO/Arduino связывает:

- пульт **Microzone MC7** и приёмник **MC8RE-V2**;
- Raspberry Pi 4 с ROS 2/Nav2;
- два BLDC-контроллера левой и правой гусеницы;
- Hall-сигналы двигателей;
- аппаратную аварийную цепь.

Основное ручное управление выполняется с пульта. Raspberry Pi получает телеметрию по USB и управляет движением только в режиме `ROS`.

## 1. Окончательная архитектура

```text
Microzone MC7
      |
    2,4 ГГц
      |
MC8RE-V2
 CH1 CH2 CH5 CH6
      |
      v
ESP32-WROOM-32 30 pin <---- USB Serial 115200 ----> Raspberry Pi 4
      |
      +-- GPIO25 DAC ----------------------------> газ LEFT
      +-- GPIO26 DAC ----------------------------> газ RIGHT
      +-- GPIO16 -> TLP240A №1 ------------------> Reverse LEFT
      +-- GPIO17 -> TLP240A №2 ------------------> Reverse RIGHT
      +-- GPIO18 -> TLP240A №3 ------------------> Low brake LEFT
      +-- GPIO19 -> TLP240A №4 ------------------> Low brake RIGHT
      +-- GPIO34 <--- Hall/Speed LEFT через 5->3,3 В
      +-- GPIO35 <--- Hall/Speed RIGHT через 5->3,3 В
      +-- GPIO32 <--- NC аварийная петля
```

`GPIO21` и `GPIO22` свободны. ESP32 не управляет `Lock/Ignition` силовых контроллеров.

## 2. Полная распиновка ESP32

| GPIO | Направление | Назначение |
|---:|:---:|---|
| 25 | OUT/DAC | Аналоговый газ левой гусеницы |
| 26 | OUT/DAC | Аналоговый газ правой гусеницы |
| 16 | OUT | Вход TLP240A №1, Reverse LEFT |
| 17 | OUT | Вход TLP240A №2, Reverse RIGHT |
| 18 | OUT | Вход TLP240A №3, Low brake LEFT |
| 19 | OUT | Вход TLP240A №4, Low brake RIGHT |
| 27 | IN | MC8RE CH1, левая гусеница |
| 33 | IN | MC8RE CH2, правая гусеница |
| 13 | IN | MC8RE CH5, RC/SAFE/ROS |
| 14 | IN | MC8RE CH6, ARM |
| 32 | IN/PULLUP | NC аварийная петля |
| 34 | IN ONLY | Hall/Speed LEFT |
| 35 | IN ONLY | Hall/Speed RIGHT |
| 2 | OUT | Светодиод состояния |
| 21 | FREE | Свободен |
| 22 | FREE | Свободен |
| 4 | FREE | Свободен |
| 23 | FREE | Свободен |
| 36 | IN ONLY | Свободный вход |
| 39 | IN ONLY | Свободный вход |

Не использовать `GPIO6–GPIO11`: они заняты Flash-памятью. `GPIO1` и `GPIO3` используются USB-UART. `GPIO0`, `GPIO2`, `GPIO5`, `GPIO12`, `GPIO15` являются загрузочными выводами и требуют осторожности.

## 3. Четыре отдельных TLP240A

Используются **четыре отдельные одноканальные TLP240A**:

| Номер | GPIO ESP32 | Функция |
|---:|---:|---|
| 1 | 16 | Reverse LEFT |
| 2 | 17 | Reverse RIGHT |
| 3 | 18 | Low brake LEFT |
| 4 | 19 | Low brake RIGHT |

### 3.1. Вход каждого TLP240A

```text
GPIO ESP32 ---- 330 Ом ---- pin 1 TLP240A
GND ESP32 ---------------- pin 2 TLP240A

GPIO ESP32 ---- 10 кОм ---- GND ESP32
```

Резистор `330 Ом` задаёт ток входного светодиода. Резистор `10 кОм` удерживает канал выключенным во время загрузки и сброса ESP32.

Перед пайкой проверить нумерацию выводов именно по даташиту используемого корпуса. Для типового DIP4:

```text
pin 1 — анод входного LED
pin 2 — катод входного LED
pin 3 — выход PhotoMOS
pin 4 — выход PhotoMOS
```

Выходные выводы `3–4` ведут себя как нормально-разомкнутый электронный контакт. Полярность выходного контакта для этой задачи несущественна.

### 3.2. Reverse LEFT

```text
ESP32 GPIO16 -> 330 Ом -> TLP240A №1 pin 1
ESP32 GND ------------> TLP240A №1 pin 2

два контакта Reverse LEFT контроллера
        |                     |
        +---- pin 3     pin 4-+
              TLP240A №1
```

### 3.3. Reverse RIGHT

```text
ESP32 GPIO17 -> 330 Ом -> TLP240A №2 pin 1
ESP32 GND ------------> TLP240A №2 pin 2

два контакта Reverse RIGHT контроллера
        |                     |
        +---- pin 3     pin 4-+
              TLP240A №2
```

### 3.4. Low brake LEFT

```text
ESP32 GPIO18 -> 330 Ом -> TLP240A №3 pin 1
ESP32 GND ------------> TLP240A №3 pin 2

два контакта Low brake LEFT
        |                     |
        +---- pin 3     pin 4-+
              TLP240A №3
```

### 3.5. Low brake RIGHT

```text
ESP32 GPIO19 -> 330 Ом -> TLP240A №4 pin 1
ESP32 GND ------------> TLP240A №4 pin 2

два контакта Low brake RIGHT
        |                     |
        +---- pin 3     pin 4-+
              TLP240A №4
```

### 3.6. Что обязательно измерить

До подключения TLP240A измерить напряжение между двумя проводами каждого разъёма:

```text
Reverse LEFT
Reverse RIGHT
Low brake LEFT
Low brake RIGHT
```

TLP240A нельзя использовать, если на разомкнутых контактах присутствует напряжение выше его допустимого выходного напряжения. Обычно `Low brake` и `Reverse` являются низковольтными управляющими входами, но это необходимо подтвердить мультиметром.

TLP240A не подключается к:

- основному питанию 48–84 В;
- фазам двигателя;
- `Lock/Ignition` без подтверждённого низкого напряжения;
- силовому контактору;
- аналоговому входу газа.

## 4. Lock/Ignition и включение контроллеров

ESP32 не управляет включением силовых контроллеров.

```text
АКБ + после предохранителя
          |
      физический ключ/тумблер
          |
          +---- Lock LEFT
          +---- Lock RIGHT
```

Аварийная кнопка должна аппаратно разрывать питание катушки силового контактора. Программная остановка ESP32 является дополнительной, а не единственной защитой.

## 5. Подключение MC8RE-V2

Приёмник питается от стабилизированных 5 В.

```text
MC8RE +   -> +5 В
MC8RE -   -> GND ESP32
```

PWM-подключение:

```text
MC8RE CH1 S ---- 1 кОм ---- GPIO27
MC8RE CH2 S ---- 1 кОм ---- GPIO33
MC8RE CH5 S ---- 1 кОм ---- GPIO13
MC8RE CH6 S ---- 1 кОм ---- GPIO14
MC8RE GND ----------------- GND ESP32
```

Рекомендуемые внешние подтяжки:

```text
GPIO27 ---- 47–100 кОм ---- GND
GPIO33 ---- 47–100 кОм ---- GND
GPIO13 ---- 47–100 кОм ---- GND
GPIO14 ---- 47–100 кОм ---- GND
```

## 6. Настройка Microzone MC7

```text
тип модели: BOAT
микширование: CH1/CH2 MIX
Speed Lock: OFF
```

При этом пульт формирует готовые команды:

```text
CH1 -> левая гусеница
CH2 -> правая гусеница
```

Ожидаемые значения:

```text
нейтраль:         CH1 ~1500, CH2 ~1500 мкс
вперёд:           CH1 >1500, CH2 >1500
назад:            CH1 <1500, CH2 <1500
поворот вправо:   CH1 >1500, CH2 <1500
поворот влево:    CH1 <1500, CH2 >1500
```

Режимы:

```text
CH5 ~1000 мкс -> RC
CH5 ~1500 мкс -> SAFE
CH5 ~2000 мкс -> ROS

CH6 ~1000 мкс -> ARM OFF
CH6 ~2000 мкс -> ARM ON
```

После включения питания требуется последовательность `ARM OFF -> ARM ON`.

Failsafe при потере радиосвязи:

```text
CH1 -> 1500 мкс
CH2 -> 1500 мкс
CH5 -> 1500 мкс, SAFE
CH6 -> 1000 мкс, ARM OFF
```

## 7. Аналоговый газ

Контроллер ожидает примерно `1–4,2 В`. Встроенный DAC ESP32 выдаёт около `0–3,3 В`.

```text
GPIO25 DAC -> буфер/масштабирующий ОУ -> Turn handle signal LEFT
GPIO26 DAC -> буфер/масштабирующий ОУ -> Turn handle signal RIGHT
```

Сигнальную землю аналогового интерфейса необходимо соединить с `Turn handle GND` соответствующего контроллера. Провод `+5V` разъёма ручки газа к ESP32 не подключать.

В прошивке первоначально установлено:

```cpp
constexpr uint8_t DAC_IDLE = 77;       // около 1,0 В
constexpr uint8_t DAC_MAX_TEST = 220;  // около 2,85 В
```

До подключения моторов проверить напряжения мультиметром.

## 8. Hall/Speed

Если отдельного выхода `Speed` нет, ответвить один Hall-канал каждого двигателя, не разрывая штатное соединение с контроллером.

```text
Hall 5 В ---- 10 кОм ----+---- GPIO34/35
                         |
                        18 кОм
                         |
Signal GND --------------+
```

При 5 В получается около 3,2 В. Для рабочего изделия предпочтителен буфер с триггером Шмитта.

GPIO34 и GPIO35 не имеют внутренних подтяжек.

## 9. Аварийная цепь

```text
GPIO32 ---- NC аварийная кнопка ---- GND ESP32
```

```text
LOW  -> цепь исправна
HIGH -> кнопка нажата, провод оборван или разъём отключён
```

Та же аварийная кнопка отдельным контактом должна разрывать питание катушки силового контактора.

## 10. Связь с Raspberry Pi

```text
Raspberry Pi USB -> USB ESP32
```

Порт обычно:

```text
/dev/ttyUSB0
/dev/ttyACM0
```

Скорость:

```text
115200 бод
```

Команды:

```text
DRV,seq,left,right*HH
ARM,seq,1*HH
ARM,seq,0*HH
STOP,seq*HH
PING,seq*HH
```

Телеметрия:

```text
TEL,millis,armed,estop_ok,targetL,targetR,actualL,actualR,
ticksL,ticksR,ppsL,ppsR,watchdog,mode,
rc_ch1_us,rc_ch2_us,rc_mode_us,rc_arm_us,rc_valid,rc_input_mode*HH
```

## 11. Сборка и прошивка

```bash
cd firmware/esp32_wroom_track_controller
pio run
pio run -t upload
pio device monitor
```

После запуска ожидается:

```text
BOOT,ESP32_WROOM_TRACK_CONTROLLER,4,TLP240A_GPIO21_22_FREE*HH
```

## 12. Безопасный первый запуск

1. Не подключать силовые моторные провода.
2. Подключить ESP32, MC8RE и четыре TLP240A.
3. Проверить мультиметром сопротивление выходов каждого TLP240A при LOW и HIGH на GPIO.
4. Проверить PWM CH1, CH2, CH5, CH6 в Serial Monitor.
5. Проверить режимы RC, SAFE и ROS.
6. Проверить ARM OFF -> ARM ON.
7. Проверить выключение пульта и failsafe.
8. Проверить аварийную кнопку.
9. Измерить напряжения на разъёмах Reverse и Low brake.
10. Подключить выходы TLP240A к одному контроллеру.
11. Проверить тормоз и реверс без подачи газа.
12. Проверить аналоговый газ на вывешенном моторе при минимальном ограничении.
13. Подключить второй контроллер только после успешной проверки первого.
