# RCWL-1655 front ultrasonic safety sensor

Current ESP32-WROOM 40-pin wiring:

| RCWL-1655 | ESP32 |
|---|---|
| VCC | 3.3 V |
| GND | GND |
| TRIG | GPIO0 |
| ECHO | GPIO39 |

GPIO39 is input-only and is used for ECHO. GPIO0 is a boot strapping pin; the RCWL-1655 TRIG input must not pull it low during reset. Do not add an external pull-down to GPIO0.

The firmware measures ECHO asynchronously using an interrupt, so no blocking `pulseIn()` call is used in the drive control loop.

Safety thresholds:

- distance above 100 cm: clear;
- 50–100 cm: NEAR warning;
- 50 cm or less for two consecutive samples: `ULTRASONIC_STOP`, local ESP32 disarm and full drive stop;
- 30 cm or less: EMERGENCY flag;
- STOP clears only after three consecutive measurements above 60 cm.

The ESP32 sends a checksummed frame every 200 ms:

`USONIC,<millis>,<distance_mm>,<valid>,<near>,<stop>,<emergency>*XX`

Example:

`USONIC,123456,742,1,1,0,0*XX`

RCWL-1655 is a close-range independent backup. LiDAR/ROS remains the primary obstacle sensor for navigation and avoidance.
