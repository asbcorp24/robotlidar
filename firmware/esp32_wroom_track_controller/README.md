# ESP32-WROOM — управление двумя гусеницами

PlatformIO/Arduino-прошивка для единого контроллера команд между:

- пультом Microzone через приёмник MC8RE-V2;
- Raspberry Pi 4 и ROS 2/Nav2;
- двумя силовыми BLDC-контроллерами гусениц.

## Приоритеты управления

После включения привод остаётся заблокированным. Для движения оператор должен сначала установить переключатель ARM в положение OFF, затем перевести его в ON.

Режим выбирается отдельным трёхпозиционным каналом пульта:

```text
низкий импульс, примерно 1000 мкс   -> ручное управление RC
середина, примерно 1500 мкс         -> безопасная блокировка
высокий импульс, примерно 2000 мкс  -> управление Raspberry Pi / ROS
```

Ручное управление через пульт является основным режимом. При переключении режима ESP32 всегда сначала обнуляет газ, включает тормоз и снимает разрешение. После этого привод нужно разрешить снова.

В автономном режиме пульт остаётся дополнительной аппаратной защитой: переключатель должен стоять в режиме ROS, а канал ARM — в разрешённом положении. При выключении пульта, потере валидных PWM-импульсов или переводе ARM в OFF привод блокируется.

## Что делает прошивка

- принимает четыре PWM-канала MC8RE-V2;
- смешивает газ и поворот в команды левой и правой гусениц;
- принимает автономные команды по USB Serial только в режиме ROS;
- формирует два аналоговых сигнала газа встроенными DAC ESP32;
- управляет тормозом, реверсом и разрешением каждого контроллера;
- плавно изменяет газ;
- перед переключением реверса обнуляет газ, включает тормоз и выдерживает паузу;
- считает Hall/Speed-импульсы обоих двигателей;
- отправляет тики, режим и значения пульта обратно Raspberry Pi;
- при потере связи, сигнала пульта, аварийной кнопке или перезагрузке выполняет безопасную остановку.

## Важное ограничение

GPIO ESP32 рассчитаны только на 3,3 В. Нельзя подавать на них 5 В от разъёма датчиков Холла, 5 В ручки газа и тем более напряжение аккумулятора.

Тонкий провод включения силового контроллера может коммутироваться напряжением аккумулятора. Он подключается только через подходящий оптрон, реле или высоковольтный транзисторный интерфейс.

|---|---:|
| Газ левой гусеницы, DAC | 25 |
| Газ правой гусеницы, DAC | 26 |
| Реверс левого контроллера | 16 |
| Реверс правого контроллера | 17 |
| Тормоз левого контроллера | 18 |
| Тормоз правого контроллера | 19 |

| Разрешение правого контроллера | 22 |
| Аварийная петля, NC на GND | 32 |

## Подключение MC8RE-V2

Приёмник питается от отдельного стабилизированного источника 5 В/BEC. Не использовать разъём `Ext Voltage` как питание — это вход измерения внешнего напряжения.

Подать питание на обычную трёхконтактную колодку канала:

```text
MC8RE +  -> +5 В BEC
MC8RE -  -> GND BEC и GND ESP32
MC8RE S  -> вход ESP32
```

Сигналы MC8RE имеют уровень 3,3 В, поэтому их можно подавать на входы ESP32 через последовательные защитные резисторы 1 кОм:

```text
MC8RE CH1 S ---- 1 кОм ---- GPIO27  руление
MC8RE CH2 S ---- 1 кОм ---- GPIO33  газ
MC8RE CH5 S ---- 1 кОм ---- GPIO13  режим
MC8RE CH6 S ---- 1 кОм ---- GPIO14  ARM
MC8RE GND ----------------- ESP32 GND
```

Рекомендуется установить по резистору 47–100 кОм от каждого RC-входа ESP32 к GND, чтобы отключённый разъём не оставлял вход в неопределённом состоянии.

Расположение функций по каналам можно изменить назначением микширования в передатчике либо GPIO в `src/main.cpp`.

## Настройка каналов пульта

Рекомендуемая логика:

```text
CH1  правый/левый ход стика -> поворот
CH2  вперёд/назад           -> газ
CH5  трёхпозиционный тумблер:
     нижнее   -> RC
     среднее  -> SAFE
     верхнее  -> ROS
CH6  двухпозиционный тумблер:
     нижнее   -> ARM OFF
     верхнее  -> ARM ON
```

Перед разрешением привода проверить в Serial Monitor значения телеметрии. Центр стиков должен быть близок к 1500 мкс, крайние положения — примерно 1000 и 2000 мкс.

Если направление стика противоположное, изменить:

```cpp
constexpr bool RC_THROTTLE_REVERSED = false;
constexpr bool RC_STEERING_REVERSED = false;
```

## Failsafe приёмника

Обязательно настроить failsafe передатчика/приёмника:

```text
газ       -> 1500 мкс, нейтраль
руление   -> 1500 мкс, центр
режим     -> 1500 мкс, SAFE
ARM       -> 1000 мкс, OFF
```

Нельзя оставлять ARM в состоянии ON при потере радиосвязи. ESP32 контролирует свежесть PWM, но настроенный failsafe является дополнительным обязательным уровнем защиты.

## Сигнал газа силовых контроллеров

Контроллер ожидает сигнал ручки газа примерно 1–4,2 В относительно собственной сигнальной земли.

Встроенный DAC ESP32 выдаёт приблизительно 0–3,3 В. Для стендового запуска прошивка ограничена примерно 1,0–2,85 В. Для полного диапазона нужен буфер/масштабирующий усилитель с rail-to-rail операционным усилителем и фактическая калибровка мультиметром.

```text
GPIO25/26 DAC -> буферный ОУ -> резистор 1 кОм -> TURN HANDLE SIGNAL
ESP32/ОУ GND -------------------------------> TURN HANDLE GND
```

Не подключать к ESP32 провод `+5V` разъёма `Turn handle`.

## Hall-сигналы

Если отдельного выхода `Speed` нет, можно высокоомно ответвить один из трёх сигнальных Hall-проводов двигателя, не разрывая его соединение с контроллером:

```text
Hall 5 В -------- 10 кОм ----+---- GPIO34 или GPIO35
                             |
                            18 кОм
                             |
Signal GND ------------------+---- ESP32 GND
```

При входных 5 В делитель даёт около 3,2 В. Для рабочего изделия предпочтительнее отдельный буфер с триггером Шмитта или гальваническая развязка.

## Аварийная петля

```text
GPIO32 ---- NC аварийная кнопка ---- GND
```

- LOW: цепь исправна;
- HIGH: кнопка нажата, провод оборван или разъём снят — привод блокируется.

Аварийная кнопка также должна аппаратно снимать разрешение с силового контактора. GPIO32 является только дополнительным программным контролем.

## Сборка и прошивка PlatformIO

```bash
cd firmware/esp32_wroom_track_controller
pio run
pio run -t upload
pio device monitor
```

Монитор порта: 115200 бод.

После запуска ожидается:

```text
BOOT,ESP32_WROOM_TRACK_CONTROLLER,2,RC_DEFAULT*HH
```

## Телеметрия

```text
TEL,millis,armed,estop_ok,targetL,targetR,actualL,actualR,
ticksL,ticksR,ppsL,ppsR,watchdog,mode,
rc_steering_us,rc_throttle_us,rc_mode_us,rc_arm_us,rc_valid*HH
```

Пример ручного режима:

```text
...,RC,1500,1500,1000,1000,1*HH
```

Пример автономного режима:

```text
...,ROS,1500,1500,2000,2000,1*HH
```

## Безопасный первый запуск

1. Вывесить обе гусеницы.
2. Сначала не подключать сигналы газа к силовым контроллерам.
3. Проверить приёмник, PWM и переключение режимов по Serial Monitor.
4. Проверить, что после выключения пульта ESP32 блокирует привод.
5. Проверить, что после перевода режима RC↔SAFE↔ROS привод блокируется.
6. Проверить аварийную петлю.
7. Измерить напряжения DAC/усилителя мультиметром.
8. Подключить только один силовой контроллер и проверить минимальный газ.
9. Только затем подключать второй контроллер.
