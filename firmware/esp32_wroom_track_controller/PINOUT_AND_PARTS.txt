ROBOTLIDAR — РАСПИНОВКА ESP32 И СПИСОК ЭЛЕМЕНТОВ
Дата: 27.11.2026

Основание: текущий локальный код firmware/esp32_wroom_track_controller.
Профиль по умолчанию: LEGACY_INTERNAL_DAC, среда PlatformIO esp32dev.
Номера ниже — GPIO ESP32, а не номера контактов гребёнки платы.
Это текстовая справка по подключениям, не новая электрическая схема.

1. ESP32: ПРИВОДЫ

GPIO25 — встроенный DAC, газ левой гусеницы LEFT.
GPIO26 — встроенный DAC, газ правой гусеницы RIGHT.
GPIO16 — направление левой гусеницы, Reverse LEFT.
GPIO17 — направление правой гусеницы, Reverse RIGHT.
GPIO12 — направление щётки, Reverse BRUSH.
GPIO4  — PWM актуатора, BTS7960 RPWM.
GPIO23 — PWM актуатора, BTS7960 LPWM.
GPIO18 — STEP модуля A4988, двигатель M4.
GPIO19 — DIR модуля A4988, двигатель M4.
GPIO15 — ENABLE модуля A4988, активный LOW.
Распиновка STEP18/DIR19/ENABLE15 согласована пользователем.

Газ щётки: выход VOUT отдельного MCP4725, I2C-адрес 0x60.
GPIO25/26 не подключаются к катушкам реле: это аналоговые выходы газа.
Направление GPIO16/17/12 подключается через выходной интерфейс/драйвер,
а не напрямую к катушке механического реле.
Полярность направления гусениц задаёт track_reverse_active_high.
У щётки в текущем коде REVERSE_ACTIVE_HIGH=true.

2. ESP32: РАДИОУПРАВЛЕНИЕ

GPIO27 — PWM CH1: команда левой гусеницы.
GPIO33 — PWM CH2: команда правой гусеницы.
GPIO14 — PWM CH3: актуатор.
GPIO5  — PWM CH4: двустороннее управление щёткой.
GPIO13 — PWM CH5: выбор RC / SAFE / ROS.
GPIO36 — UART2 RX: SBUS после инвертора; из пакета берётся CH8 для M4.

Приёмник: MC8RE-V2. Пульт: Microzone C7-MINI.
SBUS: 100000 бод, 8E2, кадр 25 байт.
GPIO36 сейчас НЕ является отдельным PWM-входом CH6.
Центральное положение CH4 останавливает щётку; стороны от центра
задают противоположные направления. Калибровки берутся из настроек.

3. ESP32: ДАТЧИКИ И ESTOP

GPIO32 — NC-петля ESTOP между GPIO32 и GND.
         LOW: петля замкнута, нормальное состояние.
         HIGH: кнопка нажата / петля разомкнута.
GPIO34 — Hall/Speed LEFT через level-конвертер (преобразователь уровней).
GPIO35 — Hall/Speed RIGHT через второй канал level-конвертера.
GPIO2  — RCWL-1655 TRIG.
GPIO39 — RCWL-1655 ECHO.

RCWL-1655: VCC=3.3 V, GND=общая земля, TRIG=GPIO2, ECHO=GPIO39.
В старом RCWL1655.md встречается GPIO0 для TRIG; в текущем исполняемом
коде ultrasonic_controller.cpp используется GPIO2. Здесь указано по коду.
Для Hall с выходами 0..5 V и level-конвертера с маркировкой HV/LV:
  HV -> 5 V, LV -> 3.3 V, GND -> общая сигнальная земля;
  Hall LEFT -> HV1; LV1 -> GPIO34;
  Hall RIGHT -> HV2; LV2 -> GPIO35.
Точная модель level-конвертера пока не указана; нужны как минимум два канала.
Hall обрабатывается при включённом hall_enabled.
GPIO34/35/36/39 — входные выводы; внутренние подтяжки у них отсутствуют.

4. ESP32: ОБЩАЯ I2C-ШИНА

GPIO21 — SDA всех I2C-устройств.
GPIO22 — SCL всех I2C-устройств.
GND    — общая сигнальная земля соответствующих модулей.

Устройство                     Адрес        Назначение
MCP23017                       0x20         Тормоза и активность приводов.
MCP4725                        0x60         Аналоговый газ щётки.
OLED SSD1315/SSD1306-совместимый 0x3C/0x3D    Дисплей.
INA228                         0x40         Измерение батареи.

A4988 не имеет I2C-адреса: M4 больше не подключается к SDA/SCL.
Питание каждого модуля подключается по его документации. Подтяжки I2C
не должны поднимать SDA/SCL ESP32 до 5 V. Если MCP4725 питается от 5 V,
его совместимость с шиной 3.3 V или согласование уровней нужно проверить.

5. MCP23017: ВСЕ ВЫХОДЫ

Вывод    Номер в API    Назначение
GPA0          0        Активность LEFT.
GPA1          1        Активность RIGHT.
GPA2          2        Активность BRUSH.
GPA3          3        Свободен.
GPA4          4        Свободен.
GPA5          5        Свободен.
GPA6          6        Свободен.
GPA7          7        Свободен.
GPB0          8        Свободен; НЕ Reverse LEFT.
GPB1          9        Реле тормоза LEFT, Brake release.
GPB2         10        Свободен; НЕ Reverse RIGHT.
GPB3         11        Реле тормоза RIGHT, Brake release.
GPB4         12        Свободен; НЕ Reverse BRUSH.
GPB5         13        Реле тормоза BRUSH, Brake release.
GPB6         14        Свободен.
GPB7         15        Свободен.

Подключение модуля MCP23017:
SDA -> GPIO21; SCL -> GPIO22; GND -> GND; питание логики -> 3.3 V.
A0/A1/A2 -> GND для адреса 0x20.
RESET не должен оставаться неподключённым; проверить его включение
на выбранном модуле. INTA/INTB отдельными GPIO ESP32 в этом коде не заняты.

GPA0..2 — существующие выходы активности, не выходы направления/тормоза.
Их нагрузка зависит от установленного оборудования; сами катушки к ним
напрямую подключать нельзя.

6. ТОРМОЗНЫЕ РЕЛЕ

Три независимых канала: LEFT, RIGHT, BRUSH.
Логические команды GPB1/GPB3/GPB5 идут на драйверы катушек с активным HIGH.
Для предусмотренного варианта COM/NC:
  катушка OFF / команда 0 -> COM соединён с NC -> тормоз применён;
  катушка ON  / команда 1 -> COM разомкнут с NC -> тормоз отпущен.

Для low-brake входа, который тормозит замыканием на свою сигнальную землю:
  COM -> вход Brake соответствующего контроллера;
  NC  -> сигнальная земля этого же контроллера.
Применимость этой логики проверить для каждой модели контроллера.
Для щётки таблица соответствует brush_brake_active_high=true;
false инвертирует управление её тормозной катушкой.

Контакты реле и катушки — разные цепи. Силовой ток двигателей через
эти сигнальные реле не пропускается. Напряжение катушек выбирается
по реально используемым реле и источнику питания, а не по GPIO ESP32.

7. АКТУАТОР И M4

BTS7960 актуатора:
  RPWM -> GPIO4;
  LPWM -> GPIO23;
  GND  -> общая сигнальная земля;
  VCC, R_EN, L_EN -> согласно существующему включению выбранного модуля.
  Отдельные GPIO для R_EN/L_EN в прошивке не назначены.
  Мотор и его силовое питание подключаются к силовой части BTS7960.

M4, A4988 STEP/DIR:
  STEP   -> GPIO18;
  DIR    -> GPIO19;
  ENABLE -> GPIO15 (LOW включает выходы, HIGH отключает);
  VDD    -> 3.3 V;
  GND    -> общая земля;
  VMOT   -> питание двигателя 8..35 V;
  RESET и SLEEP -> соединить с VDD 3.3 V;
  MS1/MS2/MS3 -> GND, полный шаг;
  1A/1B -> одна обмотка;
  2A/2B -> вторая обмотка.
Расположение контактов сверять по надписям конкретного модуля A4988.
У ENABLE нужна подтяжка 10 кОм к 3.3 V для отключения до старта MCU;
у STEP — подтяжка 10 кОм к GND. Рядом с VMOT/GND — электролит от 47 мкФ,
с допустимым напряжением выше фактического питания с запасом.
Перед работой настроить ограничение тока по двигателю и Rsense модуля;
универсального значения Vref для всех плат нет.
Мотор подключать/отключать только при снятом питании драйвера.

Код сохраняет 200 полных шагов на оборот и интервал 12 мс, как ранее.
Если двигатель/редуктор другие, STEPS_PER_REV нужно скорректировать.
Положение 0..360 градусов расчётное; HOME/энкодера нет, ноль задаётся при старте.
При остановке выходы отключаются; механическое удержание не обеспечивается.
Сигнал ready означает инициализацию GPIO, а не обнаружение A4988 по связи.

8. СЛУЖЕБНЫЕ И СВОБОДНЫЕ ВЫВОДЫ ESP32

GPIO1  — UART0 TX, связь через USB-UART.
GPIO3  — UART0 RX, связь через USB-UART.
USB Serial: 115200 бод.
GPIO0  — BOOT.
EN     — RESET.
GPIO6..GPIO11 — заняты Flash, не использовать для периферии.
GPIO18/19/15 теперь заняты A4988: STEP/DIR/ENABLE соответственно.
GPIO0/2/5/12/15 — загрузочные выводы; внешние цепи должны сохранять
корректные уровни при сбросе. GPIO12 не должен принудительно удерживаться
в HIGH внешним интерфейсом направления при старте ESP32-WROOM-32.
Используется модуль ESP32-WROOM-32 для пайки на собственную плату.
У самого модуля нет USB-разъёма и встроенного USB-интерфейса.

8.1. ПОДКЛЮЧЕНИЕ СОБСТВЕННОЙ ПЛАТЫ К RASPBERRY PI

USB Raspberry Pi -> USB-кабель данных -> USB-разъём собственной платы
-> микросхема USB-UART с логикой 3.3 V -> ESP32-WROOM-32.
USB-UART TX -> GPIO3 (RX ESP32).
USB-UART RX <- GPIO1 (TX ESP32).
GND USB-UART и ESP32 -> общая сигнальная земля.
USB D+/D- идут к USB-UART, не к GPIO1/GPIO3 напрямую.
Скорость обмена: 115200 бод. GPIO-гребёнка Raspberry Pi для связи не нужна.
GPIO0/BOOT и EN/RESET нужны для запуска и прошивки модуля.
Питание ESP32 — стабилизированные 3.3 V от отдельного источника платы;
USB-питание не объединять с ним без выбранного решения по питанию.
Модель USB-UART, тип USB-разъёма и их обвязка пока не утверждены.

10. ЭЛЕМЕНТЫ РЕЛЕЙНОГО УПРАВЛЕНИЯ

Для запрошенного варианта с механическими реле направления и тормоза:

3 шт. — реле Reverse: управление от GPIO16/GPIO17/GPIO12 через драйверы.
3 шт. — реле Brake с COM/NC: управление от MCP23017 GPB1/GPB3/GPB5.
Итого 6 механических реле, если все шесть функций реализуются именно так.
Сохранение GPIO направления не меняет это количество: GPIO задаёт только
место подключения управляющего сигнала, а не тип исполнительного элемента.

Нужны 6 каналов управления катушками, совместимых с логикой 3.3 V,
и защита каждого канала от выбросов катушки. Это могут быть готовые
релейные модули со встроенными ключами/диодами либо отдельный драйвер.
При наличии встроенных ключей и защиты второй комплект не требуется.
Для тормозных каналов требуется активный HIGH на входе модуля/драйвера.
Модель реле, напряжение катушки, контактные параметры и конкретный драйвер
пока не утверждены — произвольные артикулы здесь не подставлены.

В старой документации гусеничный Reverse выполнен через TLP240A.
Если эти существующие выходные интерфейсы сохраняются, они заменяют
соответствующие механические релейные каналы; покупать и включать оба
варианта одновременно для одной функции не требуется.

11. ПИТАНИЕ, ОБВЯЗКА И СОЕДИНЕНИЯ

Нужно предусмотреть:
  - отдельный источник 12/5 V, как задано пользователем;
  - необходимые для конкретных плат стабилизированные линии 5 V и 3.3 V;
  - отдельное силовое питание контроллеров, актуатора и шагового двигателя;
  - согласование уровней 5 PWM-входов и SBUS по фактическим напряжениям;
    для двух Hall-входов используется указанный выше level-конвертер; входы ESP32 не рассчитаны на прямые 5 V;
  - два аналоговых интерфейса газа GPIO25/26: буфер/масштабирование,
    если этого требуют входы контроллеров; внутренний DAC ESP32 не даёт 5 V;
  - согласование I2C MCP4725, если выбранный модуль требует его при 5 V;
  - подтяжки I2C и входов, развязывающие конденсаторы, если они отсутствуют
    на готовых модулях; состав проверить по фактическим платам;
  - разъёмы и провода для перечисленных сигналов и питания;
  - USB-кабель данных между ESP32 и компьютером/ROS-хостом.

Количество отдельных резисторов/конденсаторов, их номиналы, параметры
аналоговых буферов и сечения силовых проводов не определяются одной
распиновкой. Они зависят от модулей, напряжений и токов. Это пока не
окончательная закупочная спецификация дискретных деталей.

Если используются выходы активности GPA0..2, нужны три соответствующих
индикатора/существующих выходных модуля с согласованной нагрузкой.
Для работы только направления и тормоза эта индикация не обязательна.
Для автономного ROS-режима дополнительно нужен существующий ROS-хост
(Raspberry Pi/другой компьютер проекта); для ручного режима он не обязателен.

12. ЧТО ЕЩЁ НУЖНО УТОЧНИТЬ ДЛЯ ОКОНЧАТЕЛЬНОГО СПИСКА ПОКУПКИ

1) Модели трёх скутерных контроллеров и параметры Reverse/Brake/газа.
2) Модели реле и напряжение их катушек; какие интерфейсы уже установлены.
3) Напряжение, ток актуатора и параметры шагового двигателя M4.
4) Номинал/мощность шунта INA228 и измеряемое напряжение батареи.
5) Микросхема USB-UART, USB-разъём, питание 3.3 V и обвязка собственной платы.
6) Точные исполнения модулей: встроенные драйверы, защита, подтяжки,
   стабилизаторы и преобразователи уровней.

Изменены только согласованные назначения A4988: STEP18, DIR19, ENABLE15.
Направление LEFT/RIGHT/BRUSH остаётся GPIO16/17/12.
Внешний watchdog и аппаратный ARM не добавлены.
