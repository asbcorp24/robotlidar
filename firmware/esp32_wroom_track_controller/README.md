# ESP32-WROOM — управление двумя гусеницами

PlatformIO/Arduino-прошивка для промежуточного безопасного контроллера между Raspberry Pi 4 и двумя велосипедными BLDC-контроллерами 48 В.

## Что делает прошивка

- принимает команды левой и правой гусеницы по USB Serial;
- формирует два аналоговых сигнала газа встроенными DAC ESP32;
- управляет тормозом, реверсом и разрешением каждого контроллера;
- плавно изменяет газ;
- перед переключением реверса обнуляет газ, включает тормоз и выдерживает паузу;
- считает Hall/Speed-импульсы обоих двигателей;
- отправляет тики и состояние обратно Raspberry Pi;
- при потере связи, аварийной кнопке или перезагрузке включает безопасную остановку.

## Важное ограничение

GPIO ESP32 рассчитаны только на 3,3 В. Нельзя подавать на них 5 В от разъёма датчиков Холла, 5 В ручки газа и тем более напряжение аккумулятора 48 В.

Тонкий провод включения контроллера может коммутироваться напряжением аккумулятора. Он подключается только через подходящий оптрон, реле или высоковольтный транзисторный интерфейс.

## Назначение выводов ESP32-WROOM

| Функция | GPIO |
|---|---:|
| Газ левой гусеницы, DAC | 25 |
| Газ правой гусеницы, DAC | 26 |
| Реверс левого контроллера | 16 |
| Реверс правого контроллера | 17 |
| Тормоз левого контроллера | 18 |
| Тормоз правого контроллера | 19 |
| Разрешение левого контроллера | 21 |
| Разрешение правого контроллера | 22 |
| Аварийная петля, NC на GND | 32 |
| Hall/Speed левой гусеницы | 34 |
| Hall/Speed правой гусеницы | 35 |
| Светодиод состояния | 2 |

GPIO34 и GPIO35 не имеют внутренних подтягивающих резисторов.

## Сигнал газа

Контроллер электровелосипеда обычно ожидает сигнал ручки газа примерно 0,8–4,2 В относительно собственной сигнальной земли.

Встроенный DAC ESP32 выдаёт приблизительно 0–3,3 В. Для стендового запуска прошивка ограничена примерно 0,88–2,85 В. Перед эксплуатацией нужен буфер/масштабирующий усилитель с rail-to-rail операционным усилителем и фактическая калибровка мультиметром.

Рекомендуемое подключение одного канала:

```text
GPIO25/26 DAC -> буферный ОУ -> резистор 1 кОм -> THROTTLE SIGNAL
ESP32/ОУ GND -------------------------------> THROTTLE GND
```

Не подключать к ESP32 провод `+5V THROTTLE` контроллера.

## Hall-сигналы с моторного контроллера

### Предпочтительный вариант

Использовать отдельный выход `Speed` контроллера, если он имеется. Он обычно повторяет один импульсный канал скорости и не требует вмешательства в жгут коммутационных датчиков Холла.

### Если отдельного Speed нет

Можно высокоомно ответвить один из трёх сигнальных Hall-проводов двигателя, не разрывая его соединение с контроллером:

```text
Hall/Speed 5 В ---- 10 кОм ----+---- GPIO34 или GPIO35
                               |
                              18 кОм
                               |
Signal GND --------------------+---- ESP32 GND
```

При входных 5 В делитель даёт около 3,2 В. Перед подключением обязательно измерить уровни осциллографом или мультиметром. Для промышленной схемы предпочтительнее отдельный буфер/опторазвязка.

Обычный моторный Hall-разъём содержит:

```text
красный  +5 В
чёрный   GND
жёлтый   Hall A
зелёный  Hall B
синий    Hall C
```

Цвета конкретного двигателя могут отличаться. Ответвляется только один сигнальный канал на каждую гусеницу. Питание датчиков остаётся от штатного контроллера.

Прошивка определяет знак тиков по включённому направлению контроллера. Если двигатель свободно катится при выключенном приводе, один Hall-канал не позволяет достоверно определить направление. Для полной квадратурной обратной связи нужно использовать два канала на двигатель.

## Аварийная петля

Подключить нормально замкнутую аварийную кнопку между GPIO32 и GND:

```text
GPIO32 ---- NC аварийная кнопка ---- GND
```

- LOW: цепь исправна;
- HIGH: кнопка нажата, провод оборван или разъём снят — привод блокируется.

Аварийная кнопка также должна аппаратно снимать разрешение с силового контактора. GPIO32 является только дополнительным программным контролем.

## Тормоз, реверс и разрешение

Каждый сигнал подключается через оптрон или транзисторный интерфейс. В прошивке по умолчанию активный уровень высокий на стороне низковольтной интерфейсной платы.

Перед подключением определить мультиметром и документацией:

- `Low brake` или `High brake`;
- наличие отдельного `Reverse`;
- способ включения тонкого провода `Ignition/Lock`.

Белые провода самообучения не являются рабочим входом реверса.

## Сборка и прошивка PlatformIO

```bash
cd firmware/esp32_wroom_track_controller
pio run
pio run -t upload
pio device monitor
```

В VS Code открыть эту папку как отдельный PlatformIO-проект.

## Протокол USB Serial

Скорость 115200 бод, строки ASCII, окончание `\n`. После тела кадра ставится `*HH`, где `HH` — XOR всех байтов тела.

Команда движения:

```text
DRV,15,400,-250*HH
```

- `15` — номер последовательности;
- `400` — левая гусеница, диапазон -1000…1000;
- `-250` — правая гусеница.

Разрешить привод:

```text
ARM,16,1*HH
```

Снять разрешение:

```text
ARM,17,0*HH
```

Аварийная остановка:

```text
STOP,18*HH
```

Телеметрия ESP32:

```text
TEL,millis,armed,estop_ok,targetL,targetR,actualL,actualR,ticksL,ticksR,ppsL,ppsR,watchdog*HH
```

## Безопасный первый запуск

1. Снять гусеницы с земли или отсоединить моторы от механической нагрузки.
2. Не подключать силовые провода, пока не проверены все низковольтные выходы.
3. Измерить напряжения газа при выключенном и разрешённом приводе.
4. Проверить, что после отключения USB газ немедленно падает и включается тормоз.
5. Проверить аварийную петлю.
6. Проверить только один контроллер на минимальном газе.
7. Только затем подключать второй контроллер.
8. Сначала оставить максимальный DAC ограниченным значением `DAC_MAX_TEST = 220`.

## Параметры для калибровки

В `src/main.cpp`:

```cpp
constexpr uint8_t DAC_IDLE = 68;
constexpr uint8_t DAC_MAX_TEST = 220;
constexpr uint32_t COMMAND_WATCHDOG_MS = 450;
constexpr uint32_t REVERSE_BRAKE_MS = 700;
constexpr bool REVERSE_SUPPORTED = true;
```

Если отдельного входа реверса у контроллеров нет, обязательно поставить:

```cpp
constexpr bool REVERSE_SUPPORTED = false;
```
