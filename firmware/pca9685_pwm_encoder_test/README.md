# PCA9685 PWM + Encoder Test

Отдельный тестовый проект для проверки, принимает ли внешний контроллер двигателя обычный PWM-сигнал.

## Что делает

- ESP32 управляет PCA9685 по I2C.
- Энкодер меняет duty cycle от 0 до 100%.
- Один и тот же duty cycle устанавливается на все 16 выходов PCA9685.
- Текущие проценты и 12-битное значение выводятся в Serial Monitor.
- При старте PWM = 0%.

## Подключение

### PCA9685 -> ESP32

| PCA9685 | ESP32 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SDA | GPIO21 |
| SCL | GPIO22 |

Адрес PCA9685 по умолчанию: `0x40`.

Важно: `V+` на PCA9685 — отдельное питание нагрузки/серво-линий. Для теста логического PWM оно не всегда требуется; ориентируйся на конкретный модуль и вход контроллера двигателя.

### Энкодер -> ESP32

| Энкодер | ESP32 |
|---|---|
| A / CLK | GPIO17 |
| B / DT | GPIO16 |
| GND | GND |

Используются внутренние `INPUT_PULLUP`.

## PWM

По умолчанию:

```cpp
PWM_FREQ_HZ = 1000.0f;
```

На всех каналах `0..15` одинаковый duty cycle:

```text
0%   -> OFF
25%  -> 25%
50%  -> 50%
75%  -> 75%
100% -> ON
```

## Важно про BLDC-контроллер

Этот тест проверяет именно **обычный PWM duty cycle**.

Если вход газа твоего контроллера ожидает **аналоговое напряжение примерно 1–4.2 В**, PCA9685 напрямую его не заменяет. Тогда на выходе нужен RC-фильтр/буфер либо DAC.

Если контроллер ожидает **RC/servo PWM 1000–2000 мкс при ~50 Гц**, этот тест нужно переключить в другой режим формирования импульсов.

cd firmware/pca9685_pwm_encoder_test
