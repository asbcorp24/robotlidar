# Офлайн-развёртывание

## Подготовка с интернетом

1. Установить Ubuntu Server 24.04 ARM64 и ROS 2 Jazzy.
2. Скачать зависимости APT.
3. Клонировать `robotlidar` и официальный `Slamtec/sllidar_ros2`.
4. Собрать workspace.
5. Проверить запуск всех узлов.
6. Создать образ системного SSD или microSD.

## Работа без интернета

В рабочем режиме не используются:

- облачные API;
- удалённые карты;
- удалённое распознавание;
- внешние базы данных;
- интернет-службы времени.

Все вычисления выполняются локально:

- чтение Холлов и MPU6050;
- обработка `/scan`;
- EKF;
- SLAM и AMCL;
- карты стоимости;
- планирование Nav2;
- запись и воспроизведение маршрута;
- управление GPIO.

Для локального управления можно использовать прямой Ethernet или собственную
Wi-Fi-точку доступа Raspberry Pi без выхода в интернет.
